# Veilus plugins for Claude Code

A Claude Code plugin marketplace for [Veilus](https://veilus.io).

| Plugin | What it does |
|---|---|
| [`veilus`](veilus/README.md) | Run a whole Veilus campaign over MCP from one request: proxies, profiles, a tested Playwright script, a schedule, a first run and a report — with you approving the script and the plan. |

```bash
claude plugin marketplace add veilus/claude-plugin
claude plugin install veilus@veilus
```

Setup, usage and troubleshooting: [English](veilus/README.md) · [Tiếng Việt](veilus/README.vi.md).
